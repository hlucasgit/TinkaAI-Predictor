# Metodologia TinkaAI Predictor

## Objetivo

Construir una plataforma experimental para analizar historicos de sorteos usando estadistica, simulacion e inteligencia artificial.

## Pipeline

1. Carga de datos historicos.
2. Limpieza y validacion.
3. Transformacion analitica.
4. Generacion de variables.
5. Modelos estadisticos.
6. Evaluacion de modelos IA.

## Modelos considerados

- Estadistica descriptiva.
- Simulacion Monte Carlo.
- Machine Learning.
- TimesFM para evaluacion de series temporales.

## Consideracion

Los sorteos son procesos aleatorios. Los modelos se utilizaran para estudiar patrones historicos y no como garantia de resultados futuros.
