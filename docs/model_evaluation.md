# Evaluación de modelos predictivos

## Objetivo

Medir el comportamiento de los modelos aplicados a series históricas.

## Estrategia

Los datos se separan cronológicamente:

- 80% entrenamiento
- 20% validación

## Métricas

### MAE

Error absoluto promedio entre predicción y valor real.

### RMSE

Penaliza errores mayores.

## Comparaciones futuras

Se evaluarán:

- Modelo de frecuencia histórica
- Simulación Monte Carlo
- TimesFM

El objetivo es medir el aporte real de cada método sobre datos históricos.
