# TinkaAI-Predictor

Plataforma experimental de análisis estadístico e inteligencia artificial aplicada al histórico de sorteos de la Tinka.

## Objetivo

Analizar datos históricos mediante ciencia de datos, modelos probabilísticos y modelos de series temporales como TimesFM.

## Roadmap

- Preparación de datos
- Análisis estadístico
- Modelos probabilísticos
- Integración TimesFM
- API predictiva
- Dashboard

## Tecnologías

- Python
- Pandas
- NumPy
- Scikit-learn
- TimesFM
- FastAPI
